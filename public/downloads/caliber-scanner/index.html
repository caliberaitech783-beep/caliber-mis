CALIBER MIS · SCANNER SETUP

Install the Caliber PC Scanner Connector

Scan from a Brother ADS-3100 or Canon DR-C225II connected to your Windows PC, then send the pages to online MIS.

Download for Windows 64-bit

Version 1.0.7 · Windows 10/11 x64 · Includes its own Node.js runtime and native image encoder. No local MIS database or separate Node.js installation is needed.

Grayscale WebP pages, encoded once on the PC

Version 1.0.7 encodes each scanned page once on your PC as a grayscale WebP image (2400-pixel long edge), typically 100–250 KB per page with a 500 KB ceiling, about a third of the earlier JPEG size. The scanner window sends the prepared page as it is instead of compressing it again in the browser. The scanner is asked for grayscale; drivers that refuse keep colour and the connector converts the page itself. Full-resolution originals stay in %LOCALAPPDATA%\CaliberScanner\scans next to the -upload.webp copy. Online MIS must be on the release that stores WebP scans.

40-card scan entries

Each feeder scan stops after 40 cards. Scan remaining cards in another entry. Create Batch collects all saved entries for the same date, location and shift into one final batch, which can exceed 40 cards.

Canon USB detection and installation repair

Since version 1.0.6 the connector recognizes Windows driver names such as CANON DR-C225 USB #2 and the installation folder-copy error is fixed.

Updating from an older version (1.0.0 to 1.0.6): finish scanning, install this version, restart Windows once, then sign in. The updated connector starts automatically; the installer does not replace a running old process.

Install and scan

  1. Download the ZIP and extract all files into a folder.
  2. Open Install-Caliber-Scanner.cmd, review the setup details and type YES. It installs for your Windows user and creates Desktop and Start Menu shortcuts.
  3. Install the manufacturer's WIA scanner driver using the links below. Driver installation may need administrator approval.
  4. Power on the scanner and connect it to this PC by USB.
  5. Sign in to Caliber MIS, open VLB or ELB scanning and click Connect PC scanner. Allow the popup and local-network access if your browser prompts.
  6. The connected model is selected automatically. If both are detected, choose one. Load the feeder and select Scan and send to online MIS.
After installation, restart Windows once. The connector starts automatically when this Windows user signs in. Existing scanner images remain on the PC.

Official scanner drivers

  • Canon DR-C225II — ISIS / TWAIN / WIA driver

What the connector supports

Direct scanning uses the Windows WIA driver: single-sided, up to 40 cards per scan. Gemini extraction and normal validation happen in online MIS. For duplex scans or existing PDFs, use your scanner software and the MIS Upload files tab.

The connector listens only on this PC at 127.0.0.1:4174 and requires authorization from your signed-in MIS account. Scanner images are retained in %LOCALAPPDATA%\CaliberScanner\scans; the connector does not delete them automatically.

If an older connector already runs on port 4174, close it before starting this version. The installer does not replace running programs, change Windows security settings or install scanner drivers.

The Caliber package is not digitally code-signed. Use your organization's software approval process. The included Node.js runtime was checked against the official Node.js SHA-256 checksum. Physical scanning requires a connected scanner and its driver.
