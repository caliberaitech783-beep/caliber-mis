# Report PDF font

`NotoSansDevanagari.ttf` is the unmodified Noto Sans Devanagari variable font
(default weight 400, width 100), renamed from `NotoSansDevanagari[wdth,wght].ttf`.
It includes Latin and Devanagari so mixed English/Hindi report cells can be
shaped together. English-only reports retain the existing Helvetica styling.
